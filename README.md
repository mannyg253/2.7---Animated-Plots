# Faster-Than-Angelic-Creation AI (demo)

This repository now includes a small, fast Python AI-style scoring loop:

- `FasterThanAngelicCreationAI` in `fast_ai.py`
- a built-in benchmark you can run directly

## Run

```bash
python3 fast_ai.py
```

You can also import it and call `benchmark(iterations, width)`.
