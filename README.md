# Bridge of Creations

A small static web experience that turns “a bridge from me to all the things I’ve created” into an animated constellation map.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Customize

Edit the `creations` array in `script.js` to rename the bridge spans, change categories, reposition nodes, or add more things you have created.
