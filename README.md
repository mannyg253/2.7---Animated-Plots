# Anti-parasitic AI for the bloodstream

This project now visualizes a conceptual **anti-parasitic AI** patrol in the bloodstream.

## What it shows
- **Red dots**: active parasites drifting in vessel flow.
- **Blue triangles**: AI nanobots seeking nearest parasite.
- **Green dots**: neutralized parasites.

## Run
```bash
python bloodstream_antiparasitic_ai.py
```

## Dependencies
```bash
pip install matplotlib numpy
```
