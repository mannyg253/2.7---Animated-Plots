# Animated Plot: HIPAA and Sister Corporations

This repository now includes a runnable animated network visualization titled **"HIPAA and Sister Corporations"**.

## Run

```bash
python hipaa_sister_corporations_animation.py
```

## What it shows

- A central **HIPAA** node.
- Multiple **sister corporation** nodes arranged in a circle.
- Animated edges that grow outward from HIPAA to each sister node.
- A pulse effect at the central node to highlight the parent entity.
